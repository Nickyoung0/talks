## 封面点阵地球（底图是严肃的）

封面右上角是一个 canvas 绘制的点阵地球：测地网格为海，稀疏柔光点为陆，海岸线用虚线（正面亮、边缘暗两档）。**底图数据来自 Natural Earth 1:10m**（经 world-atlas TopoJSON 封装），生成管线在 `tools/gen_land_data.js`：解码多边形 → 分层处理**外环 / 洞（里海）/ 湖面 / 湖中岛**四类环 → Douglas-Peucker 抽稀 → 跨 ±180° 日界线的环整体平移到连续经度区间。**湖泊同为 10m 数据源**（ne_10m_lakes，阈值 0.05 平方度，收录鄱阳湖/洞庭湖/太湖/巢湖/洪泽湖/死海/青海湖等 458 湖 + 220 湖中岛）；湖泊形状破碎（湖湾、水道多），抽稀容差比陆地小一个量级（diag×0.005、上限 0.012°）——此前容差 0.02° 曾把洞庭湖 186 点抽到 42 点、湖心判成陆地（2026-10-26 完整性核验发现并修复）。

- 判定逻辑单独抽在 `assets/js/land-hit.js`，`globe.js` 画图、`tools/verify_geo.js` 核验共用同一份，杜绝"画的和验的不是一套"。判定用**球面射线法**（沿经线向北到北极，按 1° 经度分槽索引边）——平面射线法对横跨全球经度的环（欧亚、南极洲）会系统性出错（曾把西伯利亚北部 66–68°N 整片判成海），球面算法天然处理跨日界线的边。南极极冠由数据源截断纬度（`LAND_ANTARCTIC`，约 -85.2°）补回。
- **地理核验**：`node tools/verify_geo.js` 跑 105 项断言 —— 中国主要城市与台北/香港/海口、七大洲主要城市、主要湖泊（里海/贝加尔/五大湖等）、台湾/海南球面面积偏差（<±2%）、全球陆海占比、逐 0.5° 纬线扫描防跨日界线连片误判。改任何底图数据后必须重跑。
- **版图（最高优先级）**：依据《公开地图内容表示规范》（自然资规〔2023〕2号）。地球只画海岸线、不画国界/断续线，属“未表示国界”的示意地图；但封面以中国为视觉中心，仍按“中国全图”标准表示重要岛屿：`assets/js/key-islands.js` 手工维护 23 个岛屿点（钓鱼岛/黄尾屿/赤尾屿，澎湖/彭佳屿/兰屿/绿岛/金门/马祖，东沙、西沙、中沙、南沙群岛与黄岩岛、曾母暗沙），每岛固定一个陆地光点——它们在整球尺度下远小于 1px，海岸线抽稀与随机撒点必然丢失（2026-10-26 核验发现修复前**全部缺失**）。生成器对中国沿海（含港澳）启用保护框：小岛不按面积阈值丢弃、岸线局部细化（曾丢失香港岛、九龙南端、澳门半岛/氹仔）。`node tools/verify_territory.cjs` 跑 14 项：国土关键点（含最北/最东/最西端、藏南、阿克赛钦、台湾岛、海南岛、港澳）、规范点名岛屿清单、真实 canvas 像素核验岛屿可见（开/关岛屿点对照）、自转一整圈重要岛屿**不被封面文字压盖**（16px 安全距，当前最近 39px）、中国大陆在自转中保持入画、不画国界、全篇无不当称谓。**封面压盖的根治**：自转中南海诸岛扫过的区域最低到 y≈203px，封面标题区改为上缘锚定（`.cvo-main` flex-start + padding-top 190px，标题上缘 242px），不再垂直居中——换字体、多换一行都只会向下长；标题 `word-break: keep-all` 防止中文词被拆行。已用 7 种字体 × 2 种字号实测，最近距离恒为 39px。
- **完整性核验**：`node tools/verify_completeness.js`（对照官方 ne_10m_land.geojson 独立判定器，需先下载到 /tmp）跑 17 项断言：全球 0.5° 栅格逐点比对（湖泊口径差单独归类，真分歧 < 0.8%）、官方每个 ≥300km² 陆块的代表点判定 + 区域级面积复核（占官方 ≥60% 才算存在，防止"抽点恰好避开缺失区域"）、全球/标志性岛屿面积核算、63 项陆地 + 48 项水域地理事实清单。
- **投影朝向核验**：`node tools/verify_proj.js` 跑 19 项断言，专查"画出来的地球是否上下颠倒 / 左右镜像 / 自转方向"——北极必须在球体上半部且朝向观察者、可见半球以陆地为多的北半球为主、东京须在北京以东等相对方位全部正确（曾发现投影把地球画成南极朝上且东西镜像，已修复并纳入回归）；**自转方向**按三条物理等价判据断言：正对镜头的经度随时间西移（同太阳直射点西移）、地表特征向屏幕右侧（东）漂移、绕北极呈逆时针（2026-10-26 复核通过，源码为 `spin -= speed`）。另含**源码符号护栏**：`globe.js` 里有 3 处投影点（`px()`、陆地点内联、岸线内联），2026-10-26 曾修了 `px()` 却漏改内联两处，导致大陆点阵与海岸线整体转了 180°（西安标注周围无线点、看似落海）；护栏断言全文件不允许再出现 `cx/cy + R * (m11/m21` 旧符号、且 3 处新符号齐全。`node tools/dump_proj_svg.js /tmp/out.svg [spin度数]` 可把当前投影下的海岸线连同城市标注导出成 SVG 供人工复核。改 `globe.js` 投影/姿态后两项都要跑。
- 微调观感改 `assets/js/globe.js` 顶部 `S`：`landSample`（点数）、`landSpread`（光斑大小）、`coastDash`（虚线，`null` 回实线）、`coastA/coastB`（轮廓亮度）。`tilt` 用正值（北半球朝向观察者）；自转为自西向东（spin 递减）。

## 互动机器页（第 02 章）

把扩展机制画成一台插画风格的电脑主板（浅底网格场景、橄榄绿哑光 PCB、黑色芯片白丝印、金色接插件、细描边柔和投影；六块扩展卡各带主题色铭牌）：主板 = 内核骨架，插槽 = 扩展接口，板卡 = 扩展模块（.so），开机时序 = 代码加载时机，设备清单 = 系统目录。纯 CSS 3D + 原生 JS，无任何外部依赖。

- **整机结构**（章首）：点击任意部件（24PIN 电源 / 固件+CMOS 电池 / 芯片组 / 处理器散热 / 四条内存 / SSD / 扩展槽区 / 机箱风扇 / 后置 USB），右侧显示"硬件里是什么 / 数据库里对应什么 / 关键点"；底部可在等距 / 正视 / 俯视三种视角间切换。
- **六条插槽两条总线**：PRELOAD 总线（橙，开机前必须插好）——`pg_stat_statements`、`auto_explain`、`TimescaleDB`（自带后台进程）；ON-DEMAND 总线（青，开机后热插）——`pgvector`、`PostGIS`；外加一条留给现场 DIY `hello_pg` 的空槽。每块卡顶铭牌标注名称与加载方式。
- **开机时序**（preload 时机之后）：进入页面时机器断电，按 `→` 逐步播放八步开机时序（断电 → 通电 → 定内存 → 开机插卡 → 自带进程 → 热插拔 → 登记 → 运行），板卡有插入动画；也可直接点击右侧步骤跳转；走完最后一步再按 `→` 才翻页。
- 文案在 `tools/content/content_machine.py` 中维护（部件与步骤都是数据），布局与交互在 `assets/js/machine.js` + `assets/css/machine.css`。

## 修改与再生成

- **改活动信息**（站名 / 日期 / 地点 / 讲者）：编辑 `tools/build_slides_data.py` 顶部的 `EVENT`，然后运行：

  ```bash
  cd tools && python3 build_slides_data.py
  ```

- **改某页内容**：编辑 `tools/content/` 对应模块后重新生成。
- **章节结构**：4 章 —— 01 为什么从扩展出发 / 02 扩展如何进入执行流程（pgvector、auto_explain、pg_stat_statements 三个扩展对照 + 机制地图）/ 03 DIY 第一个扩展 / 04 回到设计哲学；pgvector 的深入拆解保留在源模块 `content_vector.py` 与详细备课材料中备查。
- **换站复用**：只改 `EVENT` 与两张配图即可，引擎无需改动。
